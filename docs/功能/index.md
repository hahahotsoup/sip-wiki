# 功能总览

sip 的功能分为三大块：**智能归档**、**辅助阅读** 与 **AI 友好**，另有规划中的能力（见 [规划中](/功能/规划)）。

| 模块 | 说明 | 详情 |
|------|------|------|
| 📚 智能归档 | 版本追踪、内容 Diff、快照归档、阅读进度记忆、来源身份与健康、内容质量标记 | [前往](/功能/归档) |
| 📖 辅助阅读 | TUI 文件夹视图、沉浸阅读、全文抓取、Markdown 渲染、今日哈汤 | [前往](/功能/阅读) |
| 🤖 AI 友好 | 全功能 CLI、统一 JSON 输出、语义搜索、LLM 摘要、结构化退出码 | [前往](/功能/AI) |
| 🕊️ 隐私与遥测 | 本地遥测苏暖泉（Sumenia），默认关闭、仅本地保存 | [前往](/功能/遥测) |
