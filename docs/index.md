## 五件事，一条主线

sip 帮你在意的，是**收集、保存、追踪、筛选、使用**你关心的信息。

```text
收集 → 保存 → 追踪 → 筛选 → 使用
```

- **收集**：RSS 订阅源、OPML
- **保存**：全文抓取、版本快照
- **追踪**：作者改了什么（Version / Diff）
- **筛选**：阅读报告、Source Policy、跨源去重、今日哈汤
- **使用**：全文 / 语义搜索、Agent、导出

底层，它只做两件事——**确定性的规则**，和**本地事实的存储**。剩下的判断交给你；AI 只是个默默关注你的助手。

## 🎯 它抓住了什么？——版本即事实

普通阅读器只告诉你「有篇文章」。sip 会告诉你：**这篇文章在 8 月 5 日被作者改过，改前改后差在哪。**

```text
v1 · 8 月 1 日   "该方案预计于明年实施，具体时间待定。"
v2 · 8 月 5 日   "该方案已确定于下月实施，共三个阶段。"   ← 悄悄改的
```

> 改动自动留档（v1/v2/v3…），`sip --diff <id> v1 v3` 一屏看清变化——这就是「版本即事实」。

## 快速上手

```bash
# 下载 Releases 中的单文件可执行程序，直接运行
./sip.exe            # Windows：进入 TUI（首次启动自动创建 readwithhotsoup/ 数据目录）
./sip.exe --help     # 或直接用 CLI
```

> sip 不是一个追求「日活」和「停留时长」的产品。它追求的是：
>
> **当你打开 sip，你知道自己在读什么、它来自哪里、有没有发生变化；当你的 AI 调用 sip，你知道它只能从你选择的信源里寻找答案。**
