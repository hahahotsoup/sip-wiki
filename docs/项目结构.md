# 项目结构

```
├── sip.csproj            # 项目文件（net10.0，版本 v1.1.45）
├── RssReader.cs          # 主程序：CLI 入口 / 订阅 / 阅读 / 检索 / AI
├── Tui.cs                # TUI 界面（文件夹视图、沉浸阅读、命令栏）
├── Sumenia.cs            # 遥测服务（苏暖泉，默认关闭，独立库）
├── simon.cs              # 安全守护与数据加密（孟思琳，默认开启、无法关闭）
├── publish.ps1           # 单文件打包脚本（win/linux/mac 各平台）
├── languages/            # 默认语言文件（编译/发布时复制到 exe 旁，同时内嵌进 exe 兜底）
│   ├── zh-CN.json        # 简体中文
│   ├── zh-Moe.json       # 喵喵风中文（抖M专属）
│   └── en-US.json
├── prompts/              # Agent 人格提示词（苏暖泉 sumenia.md / sumenia.en.md）
├── tools/                # 开发工具（语言 key 同步 add-lang-keys、压测 bench-gen / bench-run）
├── tests/Sip.Tests/      # 38 个进程级黑盒用例（CLI 契约 / SSRF 矩阵 / 去重不变量 / 终端注入 / simon）
├── .github/workflows/    # GitHub Actions CI（build + test + publish smoke）
├── .opencode/skills/     # AI Agent 使用 CLI 的 skill（sip-rss/SKILL.md）
├── docs/                 # 仓库内规划文档（如 规划-测试基线与拆TUI）
├── sip-测试报告-2026-08-11.md  # 第一轮全面测试报告（51 功能 + 30+ 异常注入 + 安全渗透 + 压测）
├── sip-完整测试报告-2026-08-12-最终版.md  # 完整测试报告（约 230+ 项，综合 8.4/10，三轮迭代 v1.0→v1.1→v1.1.4）
├── sip-v1.1-新功能测试清单.md      # v1.1 新功能测试清单（内部）
├── readwithhotsoup/    # 运行时数据目录（首次启动在 exe 同级自动创建）
│   ├── rss.db          # SQLite 数据库（挡位 3 加密为 SQLCipher）
│   ├── telemetry.db    # 遥测库（苏暖泉/Sumenia，独立于 rss.db，默认关闭）
│   ├── ai_config.json  # AI 非敏感配置（运行时生成）
│   ├── simon_events.json  # 孟思琳事件记录（数据库修复 / 拦截 / 挡位变更，最近 200 条）
│   ├── fulltext/       # 全文抓取缓存（<itemId>.md + vecs.json，挡位 3 加密为 SIPC1 格式）
│   ├── article_signals.json  # 文章标记（♥ 用户 / 🤖 AI）
│   ├── reading_progress.json  # 阅读进度记忆
│   └── languages/      # 语言文件（默认翻译复制到此处，可直接编辑）
└── README.md
```
