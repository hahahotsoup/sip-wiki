# 🤖 AI Friendly

- **Full-featured CLI**: every operation can be called from the command line
- **Unified JSON output**: `--json` lets AI parse reliably, no need to write regex
- **Embedding semantic search**: vector-based retrieval, supports local Ollama / OpenAI / DeepSeek
- **LLM summaries**: generated on demand, results cached and reused
- **Structured exit codes**: `0` success / `1` general / `2` network error / `3` resource not ready, ideal for scripting

Detailed commands in [AI Commands](/en/usage/ai-commands).
