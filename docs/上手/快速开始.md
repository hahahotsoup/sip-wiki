# 5 分钟快速开始

> 目标：**5 分钟内，从下载到第一次看见 sip 的价值**——加一个源、看今天的清单、追踪一次文章修改。

## 第 0 分钟：下载并运行

从 [Releases](https://github.com/hahahotsoup/sipintui/releases) 下载最新版**单文件可执行程序**（无需解压、无需一堆 dll）：

| 平台 | 文件 |
|------|------|
| Windows x64 | `sip-win-x64.exe` |
| Linux x64 | `sip-linux-x64` |
| macOS Intel / Apple Silicon | `sip-osx-x64` / `sip-osx-arm64` |

```bash
./sip.exe            # Windows：进入 TUI（首次启动自动创建 readwithhotsoup/ 数据目录）
./sip.exe --help     # 或直接用 CLI
./sip.exe --version  # 查看版本号（v1.1.4 起显示编译时间，如 sip v1.1.45 (built 2026-08-15 22:01)）
```

- **单文件 + 自带官方翻译**：语言文件已内嵌进 exe，数据目录缺失时自动恢复，只拷一个 exe 也能跑
- **框架依赖**：需要目标机预装 [.NET 10 运行时](https://dotnet.microsoft.com/download)（体积小）；想免装运行时用 self-contained 自行发布（见[从源码构建](/参考/构建)）
- **数据目录**：首次运行在 exe 旁自动创建 `readwithhotsoup/`——SQLite 数据库 `rss.db`、AI 配置、语言文件、全文缓存、阅读进度、遥测等**所有数据都在这**，备份/迁移整个文件夹拷走即可

## 第 1 分钟：添加你的第一个订阅源

```bash
sip -d https://blog.hotsouprealm.top/atom.xml     # 加一个源（TUI 里按 D 也行）
sip -l                                            # 列出所有订阅源，确认加进来了
```

> 也可以 `sip --import-opml 文件.xml` 批量导入（比如从 FreshRSS 导出）。

## 第 2 分钟：更新，然后读

```bash
sip -u 1             # 更新第 1 个源，拉到最新文章
sip -l 1             # 列出该源的文章
sip --show 42        # 打开一篇全屏阅读（无侧栏，按 W 进完整 TUI，Esc 返回）
```

TUI 里直接回车读，`j/k` 上下选，`Space` 翻页，`i` 沉浸阅读。**全键盘、无广告、无推荐流。**

## 第 3 分钟：看今天该读什么

```bash
sip --today          # 今日 5 篇规则式选文，附预估时长与理由
```

这就是 sip 的「今日一碗」——一天固定 5 篇，读完就关。顶部还会列出**今日变化摘要**（谁新增了、谁被改过）。

## 第 4 分钟：追踪一次"文章被改"

```bash
sip --versions 42    # 这篇文章的历史版本
sip --diff 42        # 最近两版改了什么
```

看到 diff 输出（增删行 + 前后文），你就摸到 sip 区别于 FreshRSS 的核心能力了。

## 第 5 分钟：下一步

- **想用 AI 搜索/摘要**：`sip --init` 配置模型 → `sip --index` 向量化 → `sip --search "话题" --json`
- **想挂到群里 bot**：[Bot 接入](/使用/Bot)（OpenClaw / Cherry Studio，QQ/微信/Discord/Telegram）
- **想让订阅源自动更新**：`sip --schedule 1 daily@08:00`
- **想给家人配白名单**：[实战场景 4](/上手/实战场景)
