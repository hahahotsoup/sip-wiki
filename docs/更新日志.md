# 📜 更新日志

> 版本按语义化版本（SemVer）发布。所有数据文件（`readwithhotsoup/`）互通、开放标准格式，升级不迁移、不锁死。

## v1.1.0（2026-08-12）

信息摄入闭环 + TUI 能力对齐 + 决策透明化。**新增功能尚未周全测试**，数据文件互通、可随时更换软件核心以迁移。

### 🧩 跨源去重（`--dedup`）
- 按**段落重合度**（跨源、零 LLM）检测「可能同文」：同一篇文章被多个源转发时，`--today` 顶部 / `--dedup scan` 会标出。
- `hide` 把重复篇标 `Status='dedup'`——因所有查询只读 `active`，它**自动从搜索 / 全文 / 摘要 / 计数里消失**（数据保留，非删除）。
- `dedup.json` 记录规则，`--sync` 导入时跳过，**防止卷土重来**；若被忽略那篇被作者改成不同内容，规则自动失效并重新提示。
- `undo <key>` 一键撤销恢复；manage 界面按 `i` 查看/撤销已隐藏。
- 检测是事实、决定在你、规则持久。

### 🔗 Source Policy 闭环（`--policy`）
- 把「你的决定」存成 `source_policy.json` 并**应用**：`lower_frequency`（直接改更新频率）/ `archive` / `tag`（打标签，`-l` 显示 `#tag`）/ `keep` / `unsubscribe`（记备注）。
- **`createdBy` 永远是 `user`，AI 永不自动写**——规则都经你确认。
- 让 sip 从「信息仓库」走向「信息摄入管理系统」：读 → 分析 → 你确认 → 规则生效 → 信息流变好。

### 📊 报告事实重构
- `--insights` 的 `health / action / basis` 改为 **`status`（仅技术故障：正常 / ⚠ 长期未更新 / ✗ 失败 N 次）** + **`reasons`（事实原因列表）**。
- 删掉「建议退订 / 可考虑精简」等把行为包装成价值判断的措辞；**低阅读 ≠ 低价值**，不引入黑盒评分。**（破坏性 JSON 变更：`health`→`status`、`action/basis`→`reasons`）**

### 🖥️ TUI
- 视图类抽离到 `Tui.cs`（`SidebarView` / `FeedManagerList` / `InsightsView` / `StartScreenView` 等）。
- manage：`Enter` 打开单源**编辑面板**、`s` 用**方向键选更新计划**（预设选择器）、`i` 查看已隐藏文章；底部提示改左对齐（平铺）。
- **TUI 命令行补齐与 CLI 对齐**：`diff / export / feed-info / like / dedup / policy / telemetry` 等都能在 TUI 命令行里用（输出在对话框显示），`export`/`telemetry enable` 自动 `--yes` 避免卡读。

### 🎯 Onboarding（`--onboarding`）
- 按领域（AI / 开发 / 科技公司）一键添加推荐源，降低首次使用门槛；`templates.json` 可编辑自定义清单。

### 🛰️ 遥测（苏暖泉）增强
- 新增事件：`consent_change`（同意变更审计）、`feed_change`（增/删/归档/改频率）、`search`（grep/语义搜索，记**完整查询词**，仅本机、可 `export`/`clear`，不上传）。
- 文案改为人设化：`enable` 带安全提示 + 确认；苏暖泉 来啦/已离开/已清空工作记录/默认不在。

## v1.0.0（2026-08-11）🎉 ai see you~~~~

首个正式版。本地优先的透明信息过滤器与阅读辅助器。

### 核心
- **订阅与管理**：`-l` 列表、`-d` 加源、`-u` 更新、`--sync`/`--update-all`、`--schedule` 更新调度、`-a`/`-una` 归档/去归档、`-r` 删除。
- **版本追踪**：作者改文章自动留版本（同 Guid 多版本），`--versions` 列表、`--diff` 对比（DiffPlex）、`--show` 看某版原文。
- **阅读**：TUI 文件夹视图、沉浸阅读、Markdown 渲染、全文抓取（`--fulltext`）、阅读进度记忆（Space 跳回）、来源健康状态。
- **检索**：`--grep` 全文搜索（片段模式，不依赖 AI）、`--search` 语义搜索（Embedding）。
- **AI**：`--init` 配置向导、`--index` 向量化、`--summary`/`--summary-all` LLM 摘要、结构化退出码、统一 `--json`。
- **导出**：`--export` 导出 Markdown、`--export-opml` / `--import-opml`。

### 今日哈汤（Sip Today v1）
- 规则式每日清单（近 48h 新增 / 被作者更新 / 全文质量 / ♥🤖 加权），一天固定一碗（当日缓存），`--refresh` 显式重生成。

### 阅读情况报告（Insights）
- `--insights` 按源呈现阅读事实（打开 / 读完 / 完成率 / ♥🤖 点赞 / AI 调用次数 / 订阅与积压）+ 可解释原因；遥测把 AI 调用按文章/源归因。
- `--insights-interval` 定时提醒；TUI `P` 键 / 命令 `report` 打开报告页。

### 遥测（苏暖泉 / Sumenia）
- 默认关闭、仅本地、绝不自动上传；可查看/关闭/删除/导出；`article_open/complete/progress/skip/like`、`ai_call` 事件；TUI 首次启动同意对话框。

### 工程与质量
- 修复测试报告 11 项缺陷并逐项复测；teikmmetry.db WAL + 完整性自愈；语言文件内嵌单文件；`.opencode/skills/sip-rss` skill 供 Agent 接入。
