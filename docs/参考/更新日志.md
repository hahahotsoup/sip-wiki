## v1.2.2（2026-08-20）

树状评论 + 多标签 + 数据体检 + 网页监控 + 语义 diff，证据库更灵活、更易维护、更易追踪。

- 🌳 **树状评论**：`sip ingest tree <id>` 查看树状评论（FragmentId 字段 + 递归 CTE 查询），支持 `--depth` 控制深度
- 🏷️ **多标签系统**：Tags + EvidenceTags 多对多关联
  - `sip ingest tag list` 列出所有标签
  - `sip ingest tag add <证据编号> <标签名>` 添加标签到证据
  - `sip ingest tag rm <证据编号> <标签名>` 从证据移除标签
  - `sip ingest list --tag <标签名>` 按标签筛选证据
- 📊 **Evidence 表扩展**：新增 FragmentId、Platform、ContentId、Author、CanonicalUrl、Context、Snapshot、Note、WatchEnabled、WatchInterval、WatchLastCheckedAt、WatchLastHash 等字段
- 🧹 **数据体检**：`sip ingest stats` 一行总览（证据总数 / 版本数 / 改动数 / 反转数 / 主题数 / 标签数 / 今日新增）；`sip ingest cleanup --stale` 清理过期证据——ViewCount ≥ 3 或 7 天内看过的内容自动保留，`--dry-run` 预览删除、`--json` 输出机器可读报告
- 🌐 **网页监控**：`sip ingest watch add <id>` 标记证据为监控目标（最小间隔 5 分钟）；`watch list` 列出所有监控目标；`watch refresh [id] [--all]` 手动刷新检查变化（不支持自动抓取，需自行配合 cron/任务计划）
- 🔍 **语义 diff**：`sip --diff <id> --semantic` 显示语义距离（0-1，越低越相似）和改动分级（⚪润色/🟡调整/🔴反转）
- 🧪 **测试**：新增 26 个测试用例（IngestPhase2Tests, WatchCliTests, SemanticDiffTests），总测试数达 97

## v1.2.0「广开言路」（2026-08-17）

第二扇门落地：`sip ingest` 把**非 RSS 信息**（外面查到的证据、普通网页、证据包）收进本地证据库（`rss.db` 的 `Evidence` 表，schema: `sip-evidence-v1`）——**查完即存，存了可追，追了可信**。

- 🚪 **存**：`ingest --stdin`（管道输入存为证据）/ `ingest --url <url>`（网页直存为 watch 监视，首快照 + SSRF 防护）/ `ingest --evidence <file|--stdin>`（导入 `sip-evidence-v1` 证据包，schema 校验）；`--origin` / `--producer` 记录来源与生产者
- 🗂️ **组织**：语义去重（复用 embedding）+ 主题分组（`ingest group add <label> [--seed <query>]` / `rename` / `rm`，主题由你定义，只归组不建组）
- 📡 **追踪**：版本链 + 哈希 + **双时态**（无变化不存、旧内容保留可读）；`ingest refresh [id | --stale | --all]` 重新抓取保鲜；**改动分级 ⚪润色 / 🟡调整 / 🔴反转**（反转需立场信号词双验证，只呈现不下结论）；TTL 保鲜（watch 7 天 / evidence 30 天，`--ttl` 覆盖）
- 🔍 **使用**：`ingest retrieve <query> [--top N] [--group N]` 证据随行检索（原文片段/来源/版本/新鲜度/核实/共识/主题/分级/反转）；`ingest ask <question>` **只摘录不转述**（quote verbatim, never paraphrase）；`list --stale` 浏览过期、`confirm <id>` 核实、`rm <id>` 遗忘（轻存易删）
- 🔒 **安全联动**：孟思琳挡位 2 起 `ingest` 写操作被拒；只读白名单含 `ingest list/show/retrieve/groups/ask`；`--url` 走同一套 SSRF 防护
- 🧪 **测试**：71 个进程级黑盒用例（新增 ingest CLI 契约 / 证据包校验 / SSRF / 去重 / 分组 / retrieve / ask）
- 📚 **文档**：仓库新增 `docs/用户快速手册.md`（完整命令 + TUI 按键 + 故障排查）与 `.opencode/skills/sip-rss/高级用户手册.md`（Agent 调用契约、simon 挡位纪律）
- 🛡️ **SQLitePCLRaw 漏洞修复**（core / lib.e_sqlite3 升 2.1.13）

## v1.1.4（2026-08-12）

跨源去重簇重构 + 输出爆炸根治 + 全部缺陷修复。**约 230+ 项测试、综合 8.4/10**（从 7.1「能用」到 8.4「可信任」，安全/稳定/性能短板全部补齐），+696 行零回归。完整报告见[测试报告](/测试报告)。

- 🧩 **跨源去重重构为「簇」（cluster）**：`--dedup scan` 不再输出两两配对，而是输出**重复簇**（如「发现 1 组重复簇：60 篇 · 重合度 ≥ 100% · 代表 [18818]」）；新增 **`--dedup hide-cluster <代表Id>`** 一键隐藏整簇（保留代表、隐藏其余成员）。**根治输出爆炸**：101 篇完全同文从旧版「万级配对 + 静默截断」变为「1 簇 · 357 字节 · 765ms」，无任何截断
- 🔧 **修复 exe 与源码不一致**：旧版底层把每个跨源对算了两次（双向遍历）导致 cap 预算浪费一半，簇重构一并修复（GitHub 主分支单向 `i<j` 与本地 exe 双向不一致的复制错版本问题）
- 🔍 **grep 通配符提示**：`--grep "%"`/`_` 命中但仅落在链接/HTML 属性（可见文本 0 处）时，提示「(仅命中链接/属性，未计入可见文本)」，不再出现「命中但计数 0」的困惑
- 🏷️ **`--version` 显示编译时间**：如 `sip v1.1.4 (built 2026-08-12 18:52)`，方便核对 exe 与源码版本
- 🛠️ **8 项复测全部通过**：防卷土重来（拦截 + 对照实验）、`-l N` 过滤 dedup、hide 语义校验（自嗨/无关文章都拦）、`lower_frequency` 非法计划拒绝、grep 通配符、TUI telemetry 空命令、删源孤儿规则清理、scan 性能

## v1.0.0（2026-08-11）🎉 ai see you~~~~

首个正式版。本地优先的透明信息过滤器与阅读辅助器。

### 核心
- **订阅与管理**：`-l` 列表、`-d` 加源、`-u` 更新、`--sync`/`--update-all`、`--schedule` 更新调度、`-a`/`-una` 归档/去归档、`-r` 删除。
- **版本追踪**：作者改文章自动留版本（同 Guid 多版本），`--versions` 列表、`--diff` 对比（DiffPlex）、`--show` 看某版原文。
- **阅读**：TUI 文件夹视图、沉浸阅读、Markdown 渲染、全文抓取（`--fulltext`）、阅读进度记忆（Space 跳回）、来源健康状态。
- **检索**：`--grep` 全文搜索（片段模式，不依赖 AI）、`--search` 语义搜索（Embedding）。
- **AI**：`--init` 配置向导、`--index` 向量化、`--summary`/`--summary-all` LLM 摘要、结构化退出码、统一 `--json`。
- **导出**：`--export` 导出 Markdown、`--export-opml` / `--import-opml`。

### 今日哈汤（Sip Today v1）
- 规则式每日清单（近 48h 新增 / 被作者更新 / 全文质量 / ♥🤖 加权），一天固定一碗（当日缓存），`--refresh` 显式重生成。

### 阅读情况报告（Insights）
- `--insights` 按源呈现阅读事实（打开 / 读完 / 完成率 / ♥🤖 点赞 / AI 调用次数 / 订阅与积压）+ 可解释原因；遥测把 AI 调用按文章/源归因。
- `--insights-interval` 定时提醒；TUI `P` 键 / 命令 `report` 打开报告页。

### 遥测（苏暖泉 / Sumenia）
- 默认关闭、仅本地、绝不自动上传；可查看/关闭/删除/导出；`article_open/complete/progress/skip/like`、`ai_call` 事件；TUI 首次启动同意对话框。

### 工程与质量
- 修复测试报告 11 项缺陷并逐项复测；telemetry.db WAL + 完整性自愈；语言文件内嵌单文件；`.opencode/skills/sip-rss` skill 供 Agent 接入。
