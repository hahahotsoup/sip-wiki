- 🛡️ **终端注入剥离**：TUI 标题路径与导出/渲染路径统一过滤 ANSI 转义序列（恶意源不能控制你的终端）
- 🔍 **`--grep --feed 编号` 限源**、`-l <编号> --limit M` 截断（省 token 的实测反馈）
- 🧪 **测试基线**：进程级黑盒测试（CLI 契约 / SSRF 矩阵 / dedup 不变量 / 终端注入 / FTS / simon 守护与加密），37/37 全绿；`.github/workflows/ci.yml`
- 🔧 **工程**：TUI 拆分为独立文件（`Tui.cs`，应用层 + 组件 + 领域模型归位）；语言文件去重 + 合并容错（重复 key 曾致翻译更新失效）；SQLitePCLRaw 全家升级 2.1.11（消除高危漏洞警告）

## v1.1.4（2026-08-12）

跨源去重簇重构 + 输出爆炸根治 + 全部缺陷修复。**约 230+ 项测试、综合 8.4/10**（从 7.1「能用」到 8.4「可信任」，安全/稳定/性能短板全部补齐），+696 行零回归。完整报告见[测试报告](/测试报告)。

- 🧩 **跨源去重重构为「簇」（cluster）**：`--dedup scan` 不再输出两两配对，而是输出**重复簇**（如「发现 1 组重复簇：60 篇 · 重合度 ≥ 100% · 代表 [18818]」）；新增 **`--dedup hide-cluster <代表Id>`** 一键隐藏整簇（保留代表、隐藏其余成员）。**根治输出爆炸**：101 篇完全同文从旧版「万级配对 + 静默截断」变为「1 簇 · 357 字节 · 765ms」，无任何截断
- 🔧 **修复 exe 与源码不一致**：旧版底层把每个跨源对算了两次（双向遍历）导致 cap 预算浪费一半，簇重构一并修复（GitHub 主分支单向 `i<j` 与本地 exe 双向不一致的复制错版本问题）
- 🔍 **grep 通配符提示**：`--grep "%"`/`_` 命中但仅落在链接/HTML 属性（可见文本 0 处）时，提示「(仅命中链接/属性，未计入可见文本)」，不再出现「命中但计数 0」的困惑
- 🏷️ **`--version` 显示编译时间**：如 `sip v1.1.4 (built 2026-08-12 18:52)`，方便核对 exe 与源码版本
- 🛠️ **8 项复测全部通过**：防卷土重来（拦截 + 对照实验）、`-l N` 过滤 dedup、hide 语义校验（自嗨/无关文章都拦）、`lower_frequency` 非法计划拒绝、grep 通配符、TUI telemetry 空命令、删源孤儿规则清理、scan 性能

## v1.0.0（2026-08-11）🎉 ai see you~~~~

首个正式版。本地优先的透明信息过滤器与阅读辅助器。

### 核心
- **订阅与管理**：`-l` 列表、`-d` 加源、`-u` 更新、`--sync`/`--update-all`、`--schedule` 更新调度、`-a`/`-una` 归档/去归档、`-r` 删除。
- **版本追踪**：作者改文章自动留版本（同 Guid 多版本），`--versions` 列表、`--diff` 对比（DiffPlex）、`--show` 看某版原文。
- **阅读**：TUI 文件夹视图、沉浸阅读、Markdown 渲染、全文抓取（`--fulltext`）、阅读进度记忆（Space 跳回）、来源健康状态。
- **检索**：`--grep` 全文搜索（片段模式，不依赖 AI）、`--search` 语义搜索（Embedding）。
- **AI**：`--init` 配置向导、`--index` 向量化、`--summary`/`--summary-all` LLM 摘要、结构化退出码、统一 `--json`。
- **导出**：`--export` 导出 Markdown、`--export-opml` / `--import-opml`。

### 今日哈汤（Sip Today v1）
- 规则式每日清单（近 48h 新增 / 被作者更新 / 全文质量 / ♥🤖 加权），一天固定一碗（当日缓存），`--refresh` 显式重生成。

### 阅读情况报告（Insights）
- `--insights` 按源呈现阅读事实（打开 / 读完 / 完成率 / ♥🤖 点赞 / AI 调用次数 / 订阅与积压）+ 可解释原因；遥测把 AI 调用按文章/源归因。
- `--insights-interval` 定时提醒；TUI `P` 键 / 命令 `report` 打开报告页。

### 遥测（苏暖泉 / Sumenia）
- 默认关闭、仅本地、绝不自动上传；可查看/关闭/删除/导出；`article_open/complete/progress/skip/like`、`ai_call` 事件；TUI 首次启动同意对话框。

### 工程与质量
- 修复测试报告 11 项缺陷并逐项复测；telemetry.db WAL + 完整性自愈；语言文件内嵌单文件；`.opencode/skills/sip-rss` skill 供 Agent 接入。
